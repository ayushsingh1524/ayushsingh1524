## `CASE_01` — SHOPFLOW DATA ENGINEERING

### [`shopflow-data-engineering`](https://github.com/ayushsingh1524/shopflow-data-engineering)

```text
TYPE        : DATA PIPELINE
LANGUAGE    : PYTHON
DATABASE    : POSTGRESQL
ORCHESTRATOR: AIRFLOW
RUNTIME     : DOCKER
STATE       : ACTIVE
```

An end-to-end batch data engineering system designed around a clean:

**Extract → Validate → Transform → Load**

workflow.

The system handles ingestion, transformation, validation, incremental PostgreSQL loading, duplicate prevention and automated testing.

**Engineering surface**

`Python` · `Pandas` · `SQL` · `PostgreSQL` · `Airflow` · `Docker` · `Pytest`

## `CASE_02` — ML INFERENCE PLATFORM

### [`ml-inference-platform`](https://github.com/ayushsingh1524/ml-inference-platform)

```text
TYPE        : ML INFRASTRUCTURE
API         : FASTAPI
CACHE       : REDIS
DATABASE    : POSTGRESQL
DEPLOYMENT  : DOCKER

```

A production-oriented inference platform built around asynchronous model APIs, caching, authentication and observability.

Designed as an infrastructure project rather than simply a model wrapped inside an endpoint.

**Engineering surface**

`Python` · `FastAPI` · `Redis` · `PostgreSQL` · `Docker` · `CI/CD`

## `CASE_03` — CLOUD THREAT DETECTION

### [`cloud-threat-detection`](https://github.com/ayushsingh1524/cloud-threat-detection)

```text
TYPE        : SECURITY ENGINEERING
SIGNALS     : AWS CLOUDTRAIL / IAM
WAREHOUSE   : SNOWFLAKE
AUTOMATION  : TERRAFORM
DETECTION   : SQL + YAML RULES
FRAMEWORK   : MITRE ATT&CK
```

Security analytics infrastructure for detecting suspicious activity from cloud telemetry.

Includes detection logic for account compromise, privilege escalation and suspicious AWS behavior while mapping signals against MITRE ATT&CK techniques.

**Engineering surface**

`Python` · `AWS` · `Snowflake` · `Terraform` · `SQL` · `Pytest`

---

## `CASE_04` — NETWORK PACKET ANALYZER

### [`network-packet-analyzer`](https://github.com/ayushsingh1524/network-packet-analyzer)

```text
TYPE       : SYSTEMS / NETWORK SECURITY
LANGUAGE   : C++
CAPTURE    : LIBPCAP
INTERFACE  : NCURSES
PROTOCOLS  : TCP / UDP / ARP / ICMP
```

Low-level packet inspection and threat-monitoring utility working directly with network traffic.

Implements protocol parsing and rule-based detection for behavior including SYN floods, ICMP floods and port scanning.

**Engineering surface**

`C++` · `libpcap` · `POSIX` · `ncurses` · `CMake`
